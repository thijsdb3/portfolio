# Thijs De Bock — Portfolio

A responsive personal portfolio built with React and Vite.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy to Vercel

1. Push this repository to GitHub.
2. Import the repository at https://vercel.com/new.
3. Vercel should detect Vite automatically.
4. Use `npm run build` as the build command and `dist` as the output directory.
5. Deploy.

Every push to the connected GitHub branch triggers a new deployment.

## Personalization checklist

- Add your resume PDF as `public/resume.pdf` and add a download link in the hero if desired.
- Add your LinkedIn URL when ready.
- Add the GitHub repository URL for the UNESCO project when available.
- Replace the illustrative project graphics with screenshots of your actual dashboards, maps, or analysis when you have them.

All project illustrations in this starter are CSS-generated placeholders, not screenshots of actual project outputs.
